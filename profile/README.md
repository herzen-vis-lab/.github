Разрабатываем комплексные IT-продукты для образовательных учреждений 
и организаций. Студенты, аспиранты и преподаватели работают с реальными 
проектами под руководством экспертов из IT-отрасли.

📍 Санкт-Петербург · vis-lab@herzen.spb.ru · Telegram: @ashmarev

---

## Направления

**Веб и интерфейсы** — сайты, лендинги, интернет-магазины, 
мини-приложения для образовательных учреждений

**Визуализация и картография** — интерактивные карты, 3D-туры, 
модели кампуса в формате glTF

**Прикладные сервисы** — калькуляторы, рекомендательные системы, 
инструменты для абитуриентов

**Исследования** — федеративные системы обмена данными, 
цифровое культурное наследие
