## Направления

**Веб и интерфейсы** — сайты, лендинги, интернет-магазины, мини-приложения для образовательных учреждений

**Визуализация и картография** — интерактивные карты, 3D-туры, модели кампуса в формате glTF

**Прикладные сервисы** — калькуляторы, рекомендательные системы, инструменты для абитуриентов

**Исследования** — федеративные системы обмена данными, цифровое культурное наследие

**Управление данными и ИИ-системы** — применение новых инструментов в образовательной среде
